# ML and Data Science Project Portfolio

This repository collects selected academic capstone and final projects that support my machine learning and data science portfolio. Each project includes code artifacts and supporting reports or presentation materials that show the problem framing, analysis workflow, and modeling results.

## Included Projects

### 1. Amazon Product Analytics
- Focus: product analytics, exploratory data analysis, classification, and sentiment analysis
- Highlights: data cleaning, feature engineering, logistic regression, naive Bayes, random forest, SVM, and XGBoost workflows
- Assets: Python modules, notebook, source dataset, report, and presentation

### 2. Insurance Risk Prediction
- Focus: predictive modeling for insurance risk using traditional ML and neural network approaches
- Highlights: notebook-based experimentation and comparative modeling materials
- Assets: final notebook, demo notebook, project description, report, and presentation deck

### 3. Car Insurance Risk Modeling
- Focus: predictive modeling on a car insurance dataset
- Highlights: end-to-end notebook workflow with accompanying final report
- Assets: final notebook, dataset, and report
