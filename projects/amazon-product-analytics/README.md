# Amazon Product Analytics

This capstone project analyzes Amazon product data with a combination of exploratory analysis, data preprocessing, supervised learning, and text-based sentiment workflows.

## Project Contents

- `code/new_amazon_analysis.ipynb`: main analysis notebook
- `code/data_preprocessing.py`: cleaning and feature engineering helpers
- `code/eda.py`: exploratory visualizations
- `code/logistic_regression_model.py`: logistic regression workflow
- `code/naive_bayes_model.py`: naive Bayes workflow
- `code/random_forest_model.py`: random forest workflow
- `code/sentiment_analysis.py`: sentiment analysis and text modeling workflow
- `code/Amazon_Products.csv`: project dataset
- `reports/Capstone_Report_final_group1.pdf`: final report
- `reports/6140 capstone Amazon product group1.pptx`: presentation deck

## Skills Demonstrated

- Data cleaning and preprocessing
- Feature engineering for mixed numeric and text data
- Exploratory data analysis and visualization
- Classification modeling and model comparison
- Sentiment analysis with NLP tooling
